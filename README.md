# IMDb Movies Data Analysis Using MySQL

## Project Overview
This project focuses on analyzing IMDb movie data using MySQL as part of the RSVP Movies case study.

The objective is to explore movie-related data and answer analytical questions using SQL queries.

## Tools & Technologies
- MySQL
- SQL

## SQL Concepts
- SELECT and WHERE
- Aggregate Functions
- GROUP BY and HAVING
- Joins
- Common Table Expressions (CTEs)
- Window Functions
- Ranking Functions

## Project Files
- `IMDB+dataset+import.sql` – SQL script for database setup and data import.
- `IMDb_Movies_Analysis.sql` – Check this file to see the analysis queries.
- `RSVP_moives_solution.sql` – SQL solutions for the RSVP Movies case study.

## Key Learning Outcomes
- Practiced SQL queries on movie-related data.
- Worked with joins and aggregate functions.
- Practiced CTEs and window functions for data analysis.
- Learned to structure SQL queries to answer analytical questions.
